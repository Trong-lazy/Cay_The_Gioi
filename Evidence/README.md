# Minh chứng triển khai

Lưu ảnh Console/Play Mode, log test/build và nguồn/quyền sử dụng asset sau khi có thực tế. Đặt theo task và ngày, ví dụ T01/20261002_console.png. Bản ghi Validation dẫn tới bằng chứng tương ứng. Không tạo ảnh/log giả hoặc dùng ảnh thiết kế AI làm chứng cứ gameplay đã chạy.

Không đưa save thực chứa dữ liệu cá nhân, file build lớn hoặc dump Library vào đây. Log cần đủ xác nhận phiên bản/scene/config và kết quả, tránh dữ liệu không liên quan.
