# Nguồn đồ họa Blender

Thư mục này dành cho file blend sau giai đoạn khung. Chưa yêu cầu tạo model ở các task T00–T09.

Khi triển khai đồ họa: một convention về scale/pivot/hướng, slot stage seedling/young_tree/large_tree và anchor root/leaves/trunk; xuất asset dùng trong game vào Assets/_Project/Art qua workflow Unity phù hợp. Giữ ID stage, collider click và thông số camera kiểm chứng. Ghi nguồn/quyền sử dụng asset.
